What is ROS doing?

ROS carries typed messages between separate applications and records them for replay. Our Python code decides what counts as a shake. The face is another application subscribing to the result.

One honest limitation

This is a tunable heuristic: rapid turns or repeated bumps can also trigger it. A source-time discontinuity restarts its filter.
