# Topic discovery reference

See the [debug-tools README](README.md) for complete examples and
[sensors and multiple boards](../../docs/sensors-and-boards.md) for discovery.
Connect and start acquisition before inspecting sensor topics.

```bash
ros2 topic list -t --no-daemon
ros2 topic echo /axiom/devices --qos-durability transient_local --once
```

`/axiom` is an example namespace; use the namespace in your board file. Copy the
actual IMU topic into the placeholder below:

```bash
IMU_TOPIC='PASTE_DISCOVERED_IMU_TOPIC_HERE'
ros2 topic echo "$IMU_TOPIC" sensor_msgs/msg/Imu --qos-reliability best_effort --once
```

The six-axis message includes acceleration and angular velocity, with no orientation
estimate. Extra magnetometer or IMU-temperature topics are not generated by this map.
